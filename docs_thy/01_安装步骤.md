
1. 安装依赖

需要 Bun >= 1.1 和 Node.js >= 18。

安装 Bun：curl -fsSL https://bun.com/install | bash

验证Bun：

source ~/.zshrc            （服务器的话：source ~/.bashrc）
bun --version


安装 node_modules 包：npm install

-------------------------

2. 配置环境变量中；

cp .env.example .env

编辑 .env：   。。。

---------------------------

3. 启动

首次启动一定要在 .env 中配置的是 ANTHROPIC_AUTH_TOKEN，不能是 ANTHROPIC_API_KEY，
否则会触发地域检测，配置 ANTHROPIC_AUTH_TOKEN 初始化时不会触发地域检测。
当首次登录后，可以注释掉 ANTHROPIC_AUTH_TOKEN，而启动 ANTHROPIC_API_KEY，不够也没必要。

# 交互 TUI 模式（完整界面）
./bin/claude-haha

# 无头模式（单次问答）
./bin/claude-haha -p "your prompt here"

# 管道输入
echo "explain this code" | ./bin/claude-haha -p

# 查看所有选项
./bin/claude-haha --help




CLAUDE_CODE_ENABLE_DUMP_SYSTEM_PROMPT=1 ./bin/claude-haha --dump-system-prompt
会返回系统提示词
